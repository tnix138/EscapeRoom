## ⚡ پیش‌نیازها و راه‌اندازی سریع (Local & Sandbox)

بازی به شکل پیش‌فرض از **دیتابیس SQLite توکار Node.js 22 (`node:sqlite`)** استفاده می‌کند؛ بنابراین برای اجرای محلی یا اجرای کامل تست‌ها در Sandbox **به هیچ سرویس خارجی، داکر یا کلید API نیازی ندارید!**

### پیش‌نیاز سیستم
- **Node.js نسخه `22.x` یا بالاتر**
- **npm نسخه `10.x` یا بالاتر**

### نصب و اجرا در محیط توسعه
```bash
# ۱. نصب وابستگی‌ها
npm install

# ۲. اجرای سرور توسعه (قابل دسترس روی شبکه محلی و پیش‌نمایش مرورگر)
npm run dev
```
سپس مرورگر را روی آدرس `http://localhost:3000` باز کنید. برای تجربه همزمان ۳ نفره روی یک سیستم، کافی است **۳ تب مجزا** در مرورگر باز کرده و با کد ۶ حرفی اتاق به مأموریت ملحق شوید!

## 🔐 متغیرهای محیطی (Environment Variables)

در حالت محلی و Sandbox بدون ساخت فایل `.env` همه‌چیز به صورت خودکار با ذخیره‌سازی پایدار در `.data/escaperoom.db` کار می‌کند. برای استقرار ابری (Production) متغیرهای زیر در **Vercel** تنظیم می‌شوند:

```env
# انتخاب درایور ذخیره‌سازی: 'sqlite' (پیش‌فرض محلی) یا 'supabase' (ابری)
STORAGE_DRIVER=supabase

# اطلاعات اتصال سرور به Supabase PostgreSQL (فقط سمت سرور — هرگز با پیشوند NEXT_PUBLIC منتشر نشود!)
SUPABASE_URL=https://<your-project-ref>.supabase.co
SUPABASE_SERVICE_ROLE_KEY=<your-service-role-secret-key>

# مسیر دلخواه فایل دیتابیس در حالت محلی (اختیاری)
SQLITE_DB_PATH=.data/escaperoom.db
```

## 🚀 راهنمای استقرار آنلاین (Production Deployment — Vercel + Supabase)

1. **ایجاد دیتابیس ابری در Supabase:**
   - یک پروژه جدید در Supabase بسازید.
   - فایل مهاجرت [`supabase/migrations/001_initial_schema.sql`](./supabase/migrations/001_initial_schema.sql) را در بخش SQL Editor اجرا کنید تا جدول `rooms` و ایندکس‌ها ساخته شوند.
2. **اتصال و استقرار روی Vercel:**
   - ریپازیتوری GitHub پروژه را به یک پروژه جدید در Vercel متصل کنید (Framework Preset: `Next.js`).
   - متغیرهای محیطی `STORAGE_DRIVER=supabase`، `SUPABASE_URL` و `SUPABASE_SERVICE_ROLE_KEY` را در تنظیمات Environment Variables پروژه Vercel ثبت کنید.
   - فرمان Deploy را اجرا کنید؛ اپلیکیشن بلافاصله با گواهی HTTPS فعال شده و آماده میزبانی همزمان تیم‌های ۳ تا ۶ نفره روی دسکتاپ و موبایل است.
