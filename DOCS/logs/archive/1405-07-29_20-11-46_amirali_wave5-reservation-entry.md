  `seat:<code>` و `orfeo:<code>:<token>` (همان قرارداد مسیر اتاق).

**بازنویسی‌ها**

  فوکوس روی اولین فیلد نامعتبر، انتخاب ۳–۸ با `aria-pressed` و ناوبری کلید جهت‌دار،
  ارقام فارسی، خطای سرور جدا از خطای اعتبارسنجی.
- `InviteLinksDeck.tsx` — origin فقط بعد از mount، کپی هر کارت و کپی همه با متن

- `InvitationGate.tsx` — استفاده از `rememberSeatToken` و فوکوس روی اقدام اصلی در
  حالت‌های پایانی؛ منطق API و مسیر ورود تغییر نکرده است.
- `globals.css` — استایل `.field-error`، `.guest-field.has-error`، `.guest-count-note`،
