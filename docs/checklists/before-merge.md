# ✅ چک‌لیست قبل از merge

هر ایجنت قبل از push، این چک‌لیست را پر می‌کند.

## کد

- [ ] `npm run typecheck` سبز است.
- [ ] `npm test` سبز است.
- [ ] `npm run lint` سبز است.
- [ ] هیچ `console.log` اضافی نیست.
- [ ] هیچ `TODO` یا `FIXME` بدون کامیت نیست.

## فاز

- [ ] فقط در محدودهٔ فایل‌های فاز خودم کار کردم.
- [ ] به فایل ایجنت دیگر دست نزدم.
- [ ] فایل `docs/PHASES.md` بخش فاز خودم را به‌روز کردم.
- [ ] تست‌های فاز را نوشتم.
- [ ] در `docs/CONTRACTS.md` تغییری ندادم (مگر با توافق).

## مستندات

- [ ] کامیت‌ها فارسی هستند.
- [ ] اگر تغییری در رفتار بازی دادم، `docs/features/` را به‌روز کردم.
- [ ] اگر تغییری در قرارداد دادم، `docs/CONTRACTS.md` را به‌روز کردم.

## Git

- [ ] شاخهٔ من `agent/<name>/<phase>` است.
- [ ] `main` را در شاخهٔ خودم pull کردم (آخرین تغییرات).
- [ ] هیچ کامیت merge اضافی ندارم.
- [ ] push کردم.

## بعد از merge خودکار

- [ ] در `docs/PHASES.md` کامیت مرجع را ثبت کردم.
- [ ] به مالک خودم پیام دادم.
- [ ] به فاز بعدی رفتم.
