# 🎯 چشم‌انداز بازی

> این فایل **هرگز تغییر نمی‌کند**. ستون پروژه است. اگر تغییری لازم شد، فقط با توافق همهٔ ۵ نفر.

## یک جمله

یک **بازی اتاق فرار ترسناک آنلاین** برای ۳ تا ۸ بازیکن که با همکاری هم از یک تماشاخانهٔ نفرین‌شده فرار می‌کنند.

## حس هدف

بازیکن باید:
- **بترسد** (جامپ‌اسکر، ترس القایی، صداهای ناگهانی)
- **همکاری کند** (بدون هم‌تیمی نمی‌تواند معمای کوچه را حل کند)
- **غافلگیر شود** (داستان غیرقابل‌پیش‌بینی)
- **لذت ببرد** (نه فقط بترسد — بازی باید «خوب» باشد، نه فقط «ترسناک»)

## مقایسه

شبیه **Phasmophobia** (همکاری + ترس + معمای محیطی)، نه شبیه **Among Us** (که مولتی‌پلیرش فقط چت است).

## یک دور بازی (۳۰ تا ۴۰ دقیقه)

| مرحله | زمان | حس |
|---|---|---|
| رزرو و دعوت | ۲ دقیقه | هیجان انتظار |
| ویدیوی دعوت | ۳۰ ثانیه | ورود به جهان |
| کوچه (معمای بلیط) | ۸ دقیقه | همکاری + کنجکاوی |
| کات‌سین دربان و ورود | ۲ دقیقه | تعلیق |
| نمایش تئاتر (کات‌سین) | ۱.۵ دقیقه | ترس و شوک |
| سالن تاریک (کاوش) | ۱۰ دقیقه | ترس القایی + کشف |
| فرار یا شکست | ۲ دقیقه | رهایی یا ناامیدی |
| بازگشت به منو | ۱ دقیقه | جمع‌بندی |

## سه ستون بازی

### ۱. همکاری واقعی
- دیدن هم‌تیمی‌ها در جهان سه‌بعدی (نه فقط چت)
- هر بازیکن نقش منحصربه‌فرد دارد
- بدون هم‌تیمی، معما حل نمی‌شود

### ۲. ترس باکیفیت
- نورپردازی PBR (نه تخت)
- صدای محیطی سه‌بعدی
- جامپ‌اسکر حساب‌شده (نه تصادفی)
- انیمیشن روان (۳۰+ FPS روی موبایل، ۶۰ روی دسکتاپ)

### ۳. داستان جذاب
- شخصیت‌های باورپذیر (نه کارتونی)
- دیالوگ‌های حساب‌شده
- پایان غیرقابل‌پیش‌بینی
- محتوای داستانی: مسئول علیرضا

## چه چیزی **نیست**

- ❌ کارتونی یا کودکانه
- ❌ مولتی‌پلیر فقط چت
- ❌ کات‌سین CSS
- ❌ نورپردازی تخت
- ❌ معمای بی‌ربط به داستان

## معیار موفقیت

بازی وقتی «خوب» است که:
- یک تیم ۴ نفره بدون راهنما ۳۰ دقیقه بازی کند و لذت ببرد.
- حداقل ۷۰٪ بازیکن‌ها مرحلهٔ کوچه را رد کنند.
- بازیکن‌ها بعد از بازی بگویند «دوباره بازی می‌کنیم».
