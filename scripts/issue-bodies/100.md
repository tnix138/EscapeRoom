## 🔌 ورودی ۲ — حضور هم‌تیمی‌ها (آماده است)

### 🔌 قرارداد حضور — آماده و تست‌شده در #76

📖 مرجع کامل با نمونهٔ کد: **#104**

**فرستادن موقعیت خودت (۱۰ بار در ثانیه):**

```http
POST /api/rooms/{CODE}/presence
x-seat-token: <seatToken>
Content-Type: application/json

{ "position": { "x": 1.5, "y": 1.65, "z": -3 }, "yaw": 0.42, "phase": "alley_puzzle" }
```

- ⚠️ `yaw` **رادیان** است، نه درجه.
- `playerId` و `seatIndex` را نفرست؛ سرور هویت را از توکن صندلی می‌گذارد.
- محدودهٔ کوچه: `x ∈ [-9, 9]`، `y ∈ [0, 3.2]`، `z ∈ [-18, 8]`؛ خارج از آن → `400 VALIDATION_ERROR`.
- محدودهٔ سالن: `x ∈ [-14, 14]`، `y ∈ [0, 7]`، `z ∈ [-22, 14]`.
- سقف: ۵۰ درخواست در ثانیه برای هر صندلی → `429 RATE_LIMITED`.

**دیدن هم‌تیمی‌ها:** روی استریم موجود

```ts
// GET /api/rooms/{CODE}/stream?token=<seatToken>
event: presence_update
data: { "presences": [
  { "playerId": "seat-2", "seatIndex": 1, "playerName": "علیرضا ب",
    "position": { "x": -3, "y": 1.65, "z": 2 }, "yaw": 1.2,
    "phase": "alley_puzzle", "lastUpdate": 1792610264571, "receivedAt": 1792610264571 }
], "serverNow": 1792610264622 }
```

- سرور فقط آخرین snapshot هر بازیکن را نگه می‌دارد و ۳۰ ثانیه بعد از آخرین به‌روزرسانی حذف می‌کند.
- رویدادها با هم‌جوشی ۵۰ms می‌آیند؛ تأخیر دیدن حرکت هم‌تیمی زیر ۲۰۰ms است.
- fallback: `GET /api/rooms/{CODE}/presence?token=<seatToken>`
